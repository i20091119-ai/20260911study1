# 레이디버그 먹이 사냥

경남수학문화관 **전자칠판용 수학 체험 게임**. 무당벌레를 날려 **조건에 맞는 수**(짝수·홀수·배수·크기 비교)의 열매만 골라 먹습니다.

- 파일 1개(`index.html`)로 동작 — 인터넷 없이 실행됩니다.
- 1~4인 **동시** 대결(멀티터치), 제한시간 2분.

## 놀이 방법

1. 인원(1~4명)을 고르고 규칙 안내를 본 뒤 **시작하기!**
2. 자기 화면을 **손가락으로 누르거나 끌면** 무당벌레가 그쪽으로 날아갑니다.
3. 화면 위의 **먹이 조건**(예: `3의 배수만 먹기!`)에 맞는 열매만 먹습니다.
4. 조건에 맞는 열매를 다 먹으면 새 조건으로 다음 판이 시작됩니다.
5. 2분이 끝나면 순위와 메달이 나옵니다.

### 점수

| 행동 | 점수 |
|---|---|
| 조건에 맞는 열매 | +10점 |
| 한 판 완성(조건에 맞는 열매 전부) | +20점 |
| 힌트 없이 완성 | +10점 추가 |
| 틀린 열매 | -5점 & 0.7초 어지러움(점수는 0점 미만으로 내려가지 않음) |

### 난이도 · 힌트

| 판 | 먹이 개수 | 조건 | 힌트(초록 테두리) |
|---|---|---|---|
| 1판 | 6개 | 짝수/홀수/크기 비교 | 계속 보임 |
| 2판 | 7개 | 짝수/홀수/크기 비교 | 계속 보임 |
| 3판 | 8개 | 배수 포함 전체 | 10초 뒤 보임 |
| 4판~ | 9~10개 | 배수 포함 전체 | 없음 |

판이 오를수록 열매가 떠다니는 속도도 조금씩 빨라집니다. 수는 1~20을 씁니다.

## 전자칠판 규칙 준수

제작 가이드 2장(전자칠판 제약)을 그대로 지켰습니다.

- `inset`, flex `gap`, `clamp()`/`min()`/`max()`, `mask-image`, `:has()`, `aspect-ratio` **미사용**
  (간격은 `margin`, 격자는 `display:grid` + `grid-gap`, 무당벌레·먹이 크기는 JS로 계산)
- 모든 크기를 `vmin` 기준으로 지정 — 65~86인치 화면에서도 글자가 크게 보입니다
- 조작은 `pointerdown`/`pointermove`, **여러 명이 동시에** 각자 영역을 조작합니다
  (PointerEvent 미지원 기기는 `touchstart`/`touchmove`로 자동 대체)
- 확대/축소·글자선택·길게누르기 메뉴 차단
- **외부 리소스 0개** — 폰트 링크·외부 이미지 없음, 효과음은 Web Audio로 생성
- 소리는 **시작 버튼을 누른 뒤**부터 재생(자동재생 차단 회피)
- 화면을 터치할 때마다 **밝은 소리**가 납니다(도-레-미-솔-라 오름차순, 삼각파+배음)
- 꽃 배경도 그림 파일 없이 **CSS로 그립니다** — 가운데는 비우고 아래·가장자리에만 배치해
  게임판 위의 숫자가 묻히지 않습니다

## 웹으로 배포하기

`main` 브랜치에 올라가면 `.github/workflows/deploy.yml` 이 자동으로 GitHub Pages에 배포합니다.
저장소가 **Public** 이어야 하며, 1~2분 뒤 아래 주소에서 열립니다.

```
https://i20091119-ai.github.io/20260911study1/
```

> 아직 `main` 브랜치가 없다면 Actions 탭 → **Deploy to GitHub Pages** → **Run workflow** 로
> 지금 브랜치에서 바로 배포할 수도 있습니다.

## APK로 만들기 (선택)

`https://github.com/i20091119-ai/2026knight` 의 `android/` 폴더와 `.github/workflows/apk.yml` 을
복사해 온 뒤 앱 이름 · 패키지명(`kr.gnmc.ladybug`) · 아이콘만 바꾸면 Releases에 `.apk` 가 만들어집니다.
(릴리스 파일명은 반드시 영문으로)

```

```
