# 레이디버그 대칭 놀이

경남수학문화관 **전자칠판용 수학 체험 게임**. 무당벌레 날개의 **좌우 대칭(선대칭)** 을 몸으로 익힙니다.

- 파일 1개(`index.html`)로 동작 — 인터넷 없이도 실행됩니다.
- 1~4인 **동시** 대결(멀티터치), 제한시간 2분.

## 놀이 방법

1. 인원(1~4명)을 고르고 규칙 안내를 본 뒤 **시작하기!**
2. 무당벌레 **왼쪽 날개**에 점이 찍혀 있습니다.
3. **오른쪽 날개**에서 **거울처럼 대칭이 되는 칸**을 손가락으로 누릅니다.
4. 한 마리를 완성하면 다음 무당벌레가 나오고, 판이 거듭될수록 점 개수가 늘어납니다.
5. 2분이 끝나면 순위와 메달이 나옵니다.

### 점수

| 행동 | 점수 |
|---|---|
| 대칭 칸 정답 | 5점 |
| 한 마리 완성 | 20점 |
| 힌트 없이 완성 | 10점 추가 |
| 오답 | 감점 없음(실수 횟수만 기록) |

### 난이도 · 힌트

| 판 | 날개 칸(한쪽) | 힌트(점선) |
|---|---|---|
| 1판 | 2×2 | 계속 보임 |
| 2판 | 3×2 | 계속 보임 |
| 3판 | 3×3 | 10초 뒤 보임 |
| 4판 | 4×3 | 없음 |
| 5판~ | 4×3 ~ 4×4 | 없음 |

> 3~4인일 때는 손가락 크기를 고려해 한쪽 날개를 최대 4×3으로 제한합니다.

## 전자칠판 규칙 준수

제작 가이드 2장(전자칠판 제약)을 그대로 지켰습니다.

- `inset`, flex `gap`, `clamp()`/`min()`/`max()`, `mask-image`, `:has()`, `aspect-ratio` **미사용**
  (간격은 `margin`, 격자는 `display:grid` + `grid-gap`, 크기는 JS 계산)
- 모든 크기를 `vmin` 기준으로 지정 — 65~86인치 화면에서도 글자가 크게 보입니다
- `click` 대신 `pointerdown`(PointerEvent 미지원 기기는 `touchstart`로 자동 대체)
- 확대/축소·글자선택·길게누르기 메뉴 차단
- **외부 리소스 0개** — 폰트 링크·외부 이미지 없음, 효과음은 Web Audio로 생성
- 소리는 **시작 버튼을 누른 뒤**부터 재생(자동재생 차단 회피)
